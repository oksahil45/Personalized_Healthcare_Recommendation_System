## 1. Project Overview

MEDISCOPE is an interactive healthcare intelligence application developed using Python, Machine Learning, Data Analytics, and Streamlit.

The project demonstrates how structured healthcare data can be transformed into a complete machine learning application where users can enter patient information, generate disease-category predictions, explore healthcare patterns, and access reference-based healthcare information through a single interface.

The project focuses on demonstrating an end-to-end Data Science workflow:

```text
Healthcare Dataset
        ↓
Data Cleaning
        ↓
Exploratory Data Analysis
        ↓
Feature Preparation
        ↓
Machine Learning
        ↓
Model Serialization
        ↓
Interactive Streamlit Application
        ↓
Cloud Deployment
