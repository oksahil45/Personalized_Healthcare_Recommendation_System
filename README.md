# Project Overview

MEDISCOPE is a **Personalized Healthcare & Medicine Recommendation System** developed as an end-to-end Data Science and Machine Learning project.

The application brings together:

- Healthcare dataset analysis
- Data preprocessing
- Exploratory Data Analysis
- Machine Learning classification
- Patient assessment
- Disease-category prediction
- Probability-based prediction ranking
- Healthcare reference information
- Interactive analytics
- Model transparency
- Streamlit deployment

Instead of presenting the Machine Learning model only through a notebook, MEDISCOPE converts the complete workflow into an interactive web application.

The goal is to demonstrate how a Data Science project can progress from:

**Raw Data → Analysis → Machine Learning → Application → Deployment**
