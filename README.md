# MEDISCOPE

## Personalized Healthcare & Medicine Recommendation System

MEDISCOPE is an interactive healthcare intelligence application built using Python, Machine Learning, Data Analytics, and Streamlit.

The project demonstrates an end-to-end Data Science workflow where structured healthcare data is processed, analyzed, passed through a trained Machine Learning model, and presented through an interactive web application.

> **Project Type:** Data Science / Machine Learning / Healthcare Analytics  
> **Application:** Streamlit  
> **Primary Model:** Random Forest Classifier  
> **Deployment:** Streamlit Community Cloud

# Project Overview

MEDISCOPE combines patient assessment, machine learning, healthcare references, and interactive analytics into one application.

The application allows users to:

- Explore healthcare dataset information
- Enter patient attributes
- Run a trained machine learning model
- Generate disease-category predictions
- View prediction probability information
- Explore healthcare and medicine references
- Analyze patient and disease patterns
- Review the machine learning configuration
- Understand the limitations of the model

The application is designed as an **educational and portfolio Data Science project** and is not intended for clinical diagnosis or medical prescription.

---

# Project Objective

The primary objective of MEDISCOPE is to demonstrate how Machine Learning and Data Analytics can be converted into a practical, interactive application.

Instead of keeping the project limited to a Jupyter Notebook or a trained model, the complete workflow is integrated into a Streamlit application.

The project covers:

- Data preparation
- Data analysis
- Data preprocessing
- Machine Learning
- Model serialization
- Interactive prediction
- Healthcare analytics
- Reference-based recommendations
- Visualization
- Cloud deployment
